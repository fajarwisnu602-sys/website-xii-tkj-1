CARA PAKAI (XAMPP)
1. Salin folder "tkj-xii-1" ke C:\xampp\htdocs\
2. Start Apache di XAMPP, buka http://localhost/tkj-xii-1/

TAMBAH FOTO (MUDAH):
Buka http://localhost/tkj-xii-1/upload.php  -> pilih jenis, pilih foto, klik Upload.
Password bawaan: tkj12345 (ganti di baris PASSWORD pada upload.php)

TAMBAH FOTO (MANUAL): taruh file di assets/img/utama, siswa, atau galeri
 - siswa : nama file = nama siswa, contoh Fajar Wisnu Ghaisandi.jpg
 - galeri: Kategori - Judul.jpg

GANTI DATA LAIN (visi, misi, wali kelas, sosmed): buka index.php, cari "GANTI DATA DI SINI SAJA"
